# Terraform E-Portfolio

Welcome to my E-Portfolio on the Terraform Inftastructure as Code tool!

## Slides
The presentation slides are created using [presenterm](https://github.com/mfontanini/presenterm),
which allows creating presentations in markdown.

You can either directly read the markdown files in
- [./slides/slides.md](./slides/slides.md)

or alternatively the rendered PDF version
- [./slides/slides.pdf](./slides/slides.pdf)

## Hands-On Demo
The demo tutorial is included as part of the slides,
however you can also check it out separately in
- [./slides/demo.md](./slides/demo.md)

The demo tutorial in markdown contains some extra comments,
that are excluded from the presentation.

You can find the code for the different Hands-On Demo steps in
- [./demo/steps/](./demo/steps/)
